## 1. 이번 주 목표와 완료 내용

| 계획 항목 | 구현 결과 | 확인 근거 |

## 2. 통계와 검색 이력의 기준

통계의 신규 자료는 선택한 기간에 **처음 저장되었고 현재 선택한 주제에 연결된 고유 문서**다. 발행일 기준이 아니며, 발행일이 없는 자료도 포함한다. 이미 저장된 자료를 다시 검색해도 최초 저장일은 바뀌지 않는다. 여러 주제에 연결된 자료를 전체 주제로 조회해도 중복 집계하지 않는다.

기간은 한국 시간으로 계산하고 시작일과 종료일을 모두 포함한다. 기본 기간은 오늘까지 최근 30일이며 최대 366일까지 조회할 수 있다. 잘못된 기간은 400 응답으로 처리한다. 통계에서 이동한 목록에는 `FIRST_SAVED` 기준을 적용해 통계와 같은 문서 집합을 확인하도록 했다.

읽음 비율은 해당 집합 중 현재 읽음 상태인 문서의 비율이며 소수 첫째 자리까지 반올림한다. 대상이 없으면 0%다. 읽기 상태별 수는 UNREAD·READING·READ로 제공하고 세 상태의 합은 전체 집합 수와 일치하며, 각 상태에서 해당 목록으로 이동할 수 있다. 과거의 읽기 활동 횟수나 특정 날짜 당시의 상태를 뜻하지 않는다. 보관·즐겨찾기·나중에 읽기도 현재 상태를 사용한다. 보관을 해제해도 최초 저장 자료 집합에서 문서 자체가 사라지는 것은 아니다. 공식·사용자·기타 출처를 모두 포함하며 합성 자료 수를 별도로 표시한다.

검색 이력의 기간은 문서의 최초 저장일이 아닌 **검색 작업 시작 시각** 기준이다. 페이지당 10개 작업을 제공하고 검색 결과 링크에는 해당 작업의 `runId`를 유지한다. 지표는 다음처럼 구분했다.

| 지표 | 의미 |
|---|---|
| 원시 수신 | 제공자가 반환한 organic 배열 전체 크기 |
| 제외 | 무효 URL 또는 허용 개수 상한을 넘긴 결과 |
| 유효 결과 | 저장 처리까지 완료한 입력 결과 수 |
| 고유 자료 | 해당 검색과 연결된 서로 다른 문서 수 |
| 신규 | 해당 검색에서 최초로 저장된 문서 수 |
| 기존 매칭 | 고유 자료 중 이미 저장되어 있던 문서 수 |
| 확정 중복 | 유효 결과 수에서 고유 자료 수를 뺀 값 |
| 본문 확인 불가 | 본문 상태가 BLOCKED 또는 FAILED인 문서 수 |

성공한 저장 작업은 ‘유효 결과 = 고유 자료 + 확정 중복’, ‘고유 자료 = 신규 + 기존 매칭’으로 검산할 수 있다. 수신 후 처리 실패가 발생하면 원시 수신에서 제외를 뺀 값과 저장 처리 수가 달라질 수 있다. 확정 중복은 제목이 비슷한 후보와 구분하고, METADATA_ONLY도 본문 확인 실패와 구분한다. 인증 정보·본문·개인 검색어를 이력 응답에 포함하지 않도록 했다.

## 5. 제한과 다음 일정

이번 작업에서 실제 Serper 외부 검색을 추가로 호출한 횟수는 0회다. 기존 승인 예산을 유지했고, 자동 검증은 고정 자료와 격리 환경을 사용했다. 따라서 이번 결과가 새 외부 검색 호출의 실시간 응답 품질까지 확인했다는 의미는 아니다.

과거 검색의 원시 수신(raw)·제외(excluded) 수는 저장하지 않았기 때문에 NULL, 즉 ‘미기록’으로 표시한다. 이를 0으로 추정하거나 과거 값을 복원한 것으로 처리하지 않는다. 새 검색부터 두 값을 기록하도록 구현했다.

AI 기능은 아직 구현하지 않았다. 진행도 문서상 1~8주차 범위는 완료이며, 9주차인 11월 9~15일에는 AI 없는 핵심 흐름의 통합 검증, 저장·잠금·느린 요청·중복 클릭 대응 및 새 폴더에서의 설치 안내 확인을 진행한다. 10~11주차의 Ollama와 근거 검증, 12주차 최종 통합은 미수행 상태다.

## 6. 사용자가 직접 확인할 순서

1. 미리보기 서버가 실행된 상태에서 [통계 화면](http://127.0.0.1:5178/stats)을 열고 전체 주제·최근 30일로 조회한다.
2. 기준 기록의 신규 자료 19건(실제 17건·합성 2건)과 검색 3회를 확인한다. 이후 추가 작업을 했다면 수치가 달라질 수 있다.
3. 신규 자료 숫자를 눌러 목록으로 이동하고 기간 기준이 ‘처음 저장일’인지 확인한다. 상세를 열었다가 돌아와도 조건이 유지되는지 확인한다.
4. 자료 하나를 읽음으로 표시한 뒤 통계를 다시 조회해 비율 변화를 확인한다. 보관한 다음 보관 수를 눌러 보관함에서 해당 자료를 확인한다. 이 단계의 변경은 미리보기 DB에 저장된다.
5. 날짜별 표와 그래프의 수치를 비교하고, 공식·사용자·기타 출처와 읽지 않음·읽는 중·읽음 분포를 확인한다. 읽기 상태 수를 눌러 해당 목록으로 이동하는지도 확인한다.
6. 검색 이력에서 ‘이 검색의 자료’를 눌러 선택한 작업의 자료만 나오는지 확인한다. 과거 작업의 원시 수신·제외 수는 ‘미기록’인지 확인한다.
7. 자료가 없는 과거 기간으로 조회해 건수 0, 읽음 비율 0%, 빈 상태 안내를 확인한다.
