2026-10-22 전체 백엔드 자동 테스트 24건이 실패·오류·건너뜀 없이 통과했다. ProviderTest 3건은 합성 전송으로 응답 매핑·401·429·예산을, SearchConcurrencyTest 1건은 중복·큐 제한을 확인한다. 자동 테스트는 실제 Serper를 호출하지 않는다. 실제 Serper의 오류·지연을 일부러 유발한 시험은 하지 않았다.

앱 DB의 SERPER 누적 attempts는 2다. 출처 재검토 전후 DB 대조로 이 값과 원본 검색 이력의 불변을 확인했다. 사용자는 2026-10-22 대시보드 잔여 크레딧을 **2,498**로 확인해 주었다. 대시보드는 사용자 확인값이며 에이전트가 직접 로그인해 확인한 값이 아니다. 이번에 호출 전 잔액을 다시 측정하지 않았으므로 잔액만으로 과금 단위·차감량을 단정하지 않는다. 추가 무료 검색이나 예산 초기화는 수행하지 않았다.
