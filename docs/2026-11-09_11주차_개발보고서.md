- 상태: 요약·근거 표시와 요약 모음 선행 구현, 최종 품질 검증 진행 중

## 1. 목표와 현재 결과

11주차 목표는 AI 분석을 읽기 쉬운 형태로 보여 주고, 주장과 원문 근거를 함께 확인하게 만드는 것이다. 요약, 주장, 한계, 추론을 구분하는 구조와 근거 검사, 자료별 요약 화면, 여러 자료의 요약 모음 저장 기능을 구현했다. 이는 11월 9일 기준 선행 개발이며 사람의 품질 평가까지 끝난 결과는 아니다.

## 2. 구현한 주요 기능

| 기능 | 구현 내용 |
|---|---|
| 구조화된 결과 | summary, claims, limitations, inferences를 구분해 처리한다. |
| 근거 구간 연결 | 모델이 반환한 근거 번호를 서버가 실제 입력 구간과 연결한다. |
| 잘못된 결과 차단 | 없는 근거 번호, 빈 주장, 원문에 없는 인용, 잘못된 형식은 정상 결과로 게시하지 않는다. 빈 요약도 거부하도록 추가 보강했다. |
| 출처와 상태 표시 | 본문·검색 요약 기반 여부, 모델, 생성 시각, 근거 링크, 한계·추론, 입력 변경 여부를 보여 준다. |
| 기존 결과 유지 | 새 분석에 실패하더라도 기존 유효 결과를 유지하도록 구성했다. |
| 자료 요약 모음 | 최대 5개 문서의 최신 검증 결과를 출처별로 모아 생성 시점의 스냅샷으로 저장한다. |

## 3. 부가기능과 표시 원칙

요약 모음은 서로 다른 제품이나 시점의 자료를 임의의 단일 결론으로 합치지 않는다. 자료별 출처를 유지하며, 저장 후 원문이 바뀌면 상세 화면에서 현재 자료와 비교해야 한다. 화면의 입력 해시와 구조·프롬프트 버전은 결과가 어떤 입력과 검증 방식에서 생성되었는지 구분하는 데 사용한다. 빈 요약 문제 보강 과정에서는 v2 해시를 적용해 이전 결과가 그대로 재사용되지 않도록 했다.

검색 요약만으로 생성한 분석은 원문 전체를 읽은 분석과 다르다. 근거 문자열이 입력에 존재하더라도 그 근거가 주장을 충분히 지지하는지, 중요한 내용을 빠뜨리지 않았는지는 별도 품질 판단이 필요하다.

## 4. 실제 모델에서 발견한 문제와 조치

초기 실제 모델 응답 두 건은 INVALID_EVIDENCE로 거부했다. 모델이 인용 문자열을 자유롭게 작성하는 방식에서 근거 구간 번호를 반환하는 방식으로 보강한 뒤, 입력 원문과 일치하는 인용을 연결할 수 있었다.

보강 전 성공 작업(job 4)에서 summary가 빈 문자열인 결함을 추가 발견했다. 빈 요약 거부와 v2 프롬프트·해시 구분을 적용한 뒤 최종 실제 모델 작업(job 5)은 비어 있지 않은 요약과 입력 원문에 포함된 인용 3개를 반환하며 성공했다. 이전 job 4는 stale=true로 구분된다. 구조 버전은 v1이며 프롬프트 버전은 v2다.

최종 checks.json에서 실제 Ollama 성공, 인용 일치, 동일 입력 재사용, 취소, 요약 모음 저장, 모바일 화면 및 실행 오류 없음의 6개 항목을 통과했다. 실제 생성은 합성 본문 1개에서 약 68.34초가 걸렸다. 이 결과는 해당 표본의 동작 확인이며 6가지 유형의 사람 품질 평가를 대신하지 않는다.

백엔드 자동 테스트는 58건 모두 통과했다. 이 수치는 구조 및 기존 동작 검증 결과이며 AI 내용의 정확성이나 모든 화면 흐름의 품질 점수는 아니다.

## 5. 사용자가 확인할 항목

아래는 최종 사용자 검증 항목으로, 미완료 항목을 포함한다.

- [ ] 생성된 요약이 비어 있지 않고 자료의 핵심을 반영하는지 읽어 본다.
- [ ] 주장별 근거를 원문과 비교하고, 근거가 실제로 해당 주장을 지지하는지 확인한다.
- [ ] 검색 요약 기반 표시를 보고 본문 전체 분석과 혼동하지 않는지 확인한다.
- [ ] 원문 입력이 바뀌면 기존 결과의 변경 표시를 확인한다.
- [ ] 최대 5개 자료의 요약 모음을 저장하고 출처별 구분과 저장 시점 내용을 확인한다.
- [ ] 모바일 화면에서도 요약·근거·오류 안내를 읽고 조작할 수 있는지 확인한다.

## 6. 한계와 남은 작업

공식 자료, 후기, 영문, 짧은 검색 요약, 날짜 미상, 악성 지시가 포함된 자료 등 6가지 유형에 대한 사람 품질 평가가 남아 있다. 근거 일치 검사는 사실성 전체를 보장하지 않으며, 잘못된 원문이나 문맥을 오해한 주장은 사람이 확인해야 한다. 현재 저장된 보강 전 성공 기록을 최종 품질 통과 자료로 사용하지 않는다.

## 7. 손으로 옮겨 적을 요약 5문장

1. 11주차에는 AI 결과를 요약, 주장, 한계, 추론으로 나눠 보여 주도록 구현했다.
2. 모델이 선택한 근거 번호를 원문과 연결하고 잘못된 근거는 정상 게시하지 않도록 했다.
3. 최대 5개 자료의 결과를 출처별 요약 모음으로 저장할 수 있게 했다.
4. 실제 모델 검증 중 빈 요약 문제를 발견해 거부 규칙과 버전 구분을 보강했다.
5. 여러 유형의 자료를 사람이 읽고 평가하는 시험이 남아 있어 최종 품질 완료로 판정하지 않았다.
