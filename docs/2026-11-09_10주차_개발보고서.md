# 10주차 개발 보고서

- 프로젝트: 동양미래대학교 리서치 보드
- 작성일: 2026년 11월 9일
- 계획상 해당 주차: 2026년 11월 16일~22일(9월 14일을 1주차 시작일로 가정)
- 상태: 계획 범위를 선행 구현했으며, AI 장애·복구 종합 검증은 진행 중

## 1. 목표와 현재 결과

10주차 목표는 로컬 AI가 문서를 분석할 수 있도록 연결하고, 분석 요청과 처리 상태를 저장하는 것이다. Ollama와 설치된 llama3.2:3b 모델을 연결하고 작업 접수, 대기, 실행, 성공, 실패, 취소를 다루는 코드를 구현했다. 모델을 새로 다운로드하거나 외부 유료 AI로 자료를 보내지 않았다.

이 보고서는 11월 9일에 수행한 선행 개발을 정리한 것이다. 해당 주차의 모든 시험이 끝났다는 의미가 아니며, 구현 사실과 검증 결과를 구분한다.

## 2. 구현한 주요 기능

| 기능 | 구현 내용 |
|---|---|
| 로컬 AI 연결 | 로컬 Ollama 주소 127.0.0.1:11434와 llama3.2:3b 모델을 사용한다. |
| 작업 저장 | 문서별 입력 스냅샷·해시, 모델, 상태, 결과, 오류, 생성·완료 시각을 저장한다. |
| 비동기 요청 | 요청을 접수하면 HTTP 202를 반환하고 별도 작업으로 처리한다. |
| 처리량 제한 | 단일 실행, 활성 작업 5개 및 실제 큐 5개 제한을 적용했다. 자동 재시도는 0회다. |
| 결과 재사용 | 같은 입력과 모델로 성공한 결과를 재사용하도록 구현했다. 검증 방식이 변경된 결과는 버전 구분이 필요하다. |
| 취소와 재시작 처리 | 취소 후 결과 저장을 막고, 서버 재시작 시 중단 작업을 FAILED/INTERRUPTED로 처리하도록 구현했다. |

## 3. 부가기능과 입력 보호

- 입력은 본문 앞 8,000자 또는 검색 요약 앞 2,000자로 제한하며 사용자 메모는 포함하지 않는다.
- 제목만 있는 자료는 분석하지 않는다. 본문과 검색 요약을 구분해 사용한다.
- 모델에는 셸 실행, DB 접근, 웹 도구 권한을 주지 않는다.
- AI 요청의 180초 제한이 응답 본문 수신 완료까지 적용되도록 수신 방식을 보강했다. 실제 timeout 전체 시험은 별도로 남아 있다.
- Ollama가 꺼져도 원문 보기, 보관, 메모 등 기존 기능을 이용할 수 있도록 구성했다.
- 취소는 결과 게시 중단을 뜻하며, 이미 시작한 모델 계산 자체의 중단을 보장하지 않는다.

## 4. 확인한 검증과 해석

백엔드 최종 빌드 로그에서 자동 테스트 58건, 실패 0건, 오류 0건, 건너뜀 0건과 BUILD SUCCESS를 확인했다. 기존 54건에 AI 검증 테스트 4건이 추가된 결과이며, 모든 AI 장애 상황을 시험한 수치는 아니다.

실제 모델의 초기 두 응답은 근거가 유효하지 않아 INVALID_EVIDENCE로 거부되었다. 이후 근거 구간 번호를 원문에 연결하는 방식으로 바꿔 성공 상태를 얻었지만, 그 결과의 요약이 빈 문자열인 문제를 추가 발견했다. 빈 요약 거부와 v2 입력 해시 구분을 보강한 뒤 실제 모델 재검증을 통과했다. 최종 작업(job 5)은 비어 있지 않은 요약과 입력에 존재하는 인용 3개를 반환했다. 합성 본문 1개에서 생성까지 약 68.34초가 걸렸으며, 이 결과를 다양한 자료의 품질 검증 완료로 확대하지 않는다.

기존 메모·보관 기능 7개 그룹과 통계 기능 6개 그룹의 회귀 검증 결과도 확인했다. 브라우저 검증 그룹과 자동 테스트 건수는 서로 다른 단위이므로 합산하지 않는다. 실제 외부 검색 Serper 추가 호출은 0회다.

## 5. 사용자가 확인할 항목

아래 항목은 사용자가 최종 확인할 체크리스트이며, 모두 통과했다는 기록은 아니다.

- [ ] 본문이 있는 자료의 분석을 요청하고 대기·실행·완료 상태를 확인한다.
- [ ] 같은 입력으로 다시 요청했을 때 결과 재사용 여부를 확인한다.
- [ ] 모델이 꺼져 있거나 없을 때 실패 안내를 보고, 보관·메모는 계속 이용한다.
- [ ] 실행 중 취소한 작업의 결과가 나중에 정상 결과로 게시되지 않는지 확인한다.
- [ ] AI 실행 중 서버를 재시작한 뒤 중단 안내와 기존 자료 보존을 확인한다.

## 6. 한계와 남은 작업

실제 AI의 timeout, 메모리 부족, 취소 및 재시작 복구 전체 조합을 검증하지 못했다. 최종 검사에서 실제 모델 성공, 동일 입력 재사용, 취소, 요약 모음 저장, 모바일 화면을 확인했지만 전체 장애 시험을 대체하지 않는다. 6가지 자료 유형의 사람 품질 평가도 남아 있다. 현재 단계는 AI 처리 기반을 구현하고 검증을 보강하는 단계다.

## 7. 손으로 옮겨 적을 요약 5문장

1. 10주차에는 로컬 AI를 연결하고 문서 분석 작업의 상태와 결과를 저장하도록 구현했다.
2. 한 번에 처리하는 작업과 대기 요청을 제한하고, 같은 입력의 결과를 재사용하도록 했다.
3. 분석에는 본문이나 검색 요약만 사용하며 사용자 메모는 넣지 않는다.
4. 자동 테스트 58건은 통과했지만 실제 AI 결과에서 빈 요약 문제를 발견해 검증을 강화했다.
5. 취소와 재시작 복구의 전체 시험이 남아 있어 10~12주차 전체 완료로 판정하지 않았다.
