# 화면 가독성과 사용 흐름 개선

2026-10-28. 7주차 기능을 유지하면서 프론트엔드의 목록·상세·탐색 구조를 개선했다.

- 목록 첫 화면에는 제목 검색·관심 주제·출처만 배치하고 기간·읽기 상태·정렬·페이지 크기는 펼쳐서 선택한다. 필터 초기화는 검색 runId를 유지한다.
- 결과 수를 목록 바로 위에 표시한다. 제목을 누르면 상세로 이동하며 출처 근거와 추출 사유는 펼쳐서 읽는다.
- 본문 글씨와 보조 설명의 대비·행간을 높이고 반복 상태 안내를 줄였다. 보관 버튼은 선택 여부에 따라 색과 문구가 함께 바뀐다.
- 상단의 장식용 검색 표시를 실제 저장 자료 제목 찾기로 연결하고 새 자료 검색 링크를 추가했다.
- 상세 상단에 목록 복귀·메모 작성 바로가기를 추가했다. 보관·읽기 조작을 제목 아래로 옮기고 넓은 화면에서 메모와 주제 연결을 나란히 배치했다.
- 사이드바는 화면 높이에 맞춰 고정한다. 준비 중인 주제 분석을 표시하고, 키보드 본문 건너뛰기와 포커스 표시를 제공한다. 좁은 화면에서는 한 열로 재배치한다.

검증: TypeScript/Vite build·ESLint 통과. Edge 실제 브라우저에서 상단 제목 찾기, 목록 필터 초기화, 상세 필터 펼치기와 페이지 크기, 상세 이동을 확인했다. 1440px 목록·상세와 390px 목록·상세를 캡처하고 가로 넘침을 검사했다. 별도 fake 시험 DB에서 기존 week7.mjs의 7개 검증 그룹(메모 실패·복원·충돌, 보관함, 주제 연결 등)을 다시 통과했다. 사용자 미리보기 DB에는 검증용 기록을 쓰지 않았다. 전체 접근성 인증이나 사용자 조사 결과를 뜻하지 않는다.
