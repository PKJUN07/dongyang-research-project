## 수행한 개발

### 제공자 분리와 응답 정리

검색어·언어·지역·페이지·결과 수를 공통 입력으로 정의하고, 제공자별 응답을 공통 검색 결과로 변환했다. URL이 없거나 허용하지 않는 형식인 항목은 제외한다. 제목이나 검색 요약이 없을 때의 처리도 정했다. 정상 빈 배열은 성공 0건으로 처리하고, 잘못된 JSON이나 결과 구조는 제공자 오류로 구분한다.

### 인증과 비용 제한

API 키는 Java 서버 환경변수에서만 읽는다. 기본 모드는 fake이며, 외부 검색 승인 설정과 키가 모두 있어야 실제 요청을 수행한다. 브라우저 설정이나 VITE 환경변수에는 키를 넣지 않는다.

최초 검색은 1페이지·최대 10건, 자동 재시도 0회로 제한했다. 실제 요청 시도 횟수는 전송 전에 DB에 기록하고 재시작 후에도 누적 상한 2회를 유지한다. 실패도 이미 전송됐을 수 있으므로 사용 횟수를 되돌리지 않는다. 429 응답의 Retry-After를 반영해 대기 중 재요청을 차단한다.

### 검색 상태와 화면

비동기 작업은 QUEUED, RUNNING, SUCCEEDED, PARTIAL, FAILED 상태로 관리한다. 화면은 실행 중에만 상태를 주기적으로 조회하고 완료·실패 시 폴링을 멈춘다. 중복 클릭 방지와 서버의 요청 키 재전송 보호를 함께 적용했다. 오류가 나도 검색어 입력은 유지한다.

### 실제 시험 준비

키를 화면에 표시하지 않고 입력받아 서버를 시작하는 Start-ApprovedSearch.ps1과 승인된 두 검색어를 시험하는 Invoke-ApprovedSearchSmoke.ps1을 작성했다. 시험 스크립트는 요청 키를 로컬 기록에 먼저 저장하며, 재실행 시 동일한 작업을 조회하도록 구성했다. 실제 시험 스크립트는 종료 코드 0으로 실행을 마쳤다.

### 실제 검색 시험 기록

2026년 10월 16일 한국 시간 기준이다. 시간은 검색 접수·상태 폴링·결과 조회를 포함한 전체 관측값이며, Serper 네트워크 응답 시간만을 따로 측정한 값이 아니다.

| 검색어 | 작업 ID | 완료 시각 | 저장 결과 수 | 전체 관측 시간 | 작업 상태 |
|---|---:|---|---:|---:|---|
| 애슐리 퀸즈 | 1 | 15:14:10 | 7 | 약 3.32초 | SUCCEEDED |
| 클로드 | 2 | 15:14:12 | 10 | 약 2.15초 | SUCCEEDED |

17건 모두 synthetic=false이며 제목·URL·검색 요약을 저장했다. 이랜드이츠와 Claude 제품 페이지 등의 공식 후보, 블로그·동영상 등의 사용자 글 후보가 포함됐다. 후보의 운영 주체와 분류 근거는 4주차에서 확인한다. 현재 분류는 OTHER이며, 본문은 POLICY_NOT_APPROVED 사유로 METADATA_ONLY다.

원본 실행 기록은 backend/data/approved-search-smoke.json에 보관했다. 실제 검색 자료를 포함하므로 소스 배포물에 포함하지 않는다. 최초 로컬 접속 실패는 샌드박스 소켓 권한 제한이었고, 권한 있는 실행에서 정상 서버를 확인했다.

## 남은 완료 조건

1. 서버 준비와 승인된 두 검색어의 실제 호출은 완료했다. 같은 검증을 위해 검색을 다시 호출하지 않는다.
2. 실제 결과를 브라우저에서 조회하고 새로고침 후 같은 runId로 복원되는지 확인한다.
3. 4주차에서 공식 후보와 사용자 글 후보의 운영 주체·내용·정책을 확인한다. 검색 순위만으로 공식 여부를 확정하지 않는다.
4. 계정 대시보드에서 실제 무료 크레딧 차감을 확인한다. 호출 횟수와 과금 크레딧이 같다고 추정하지 않는다.
5. 남은 검증을 마친 뒤 완료 보고서로 갱신한다. 실제 요청은 이미 성공했으므로 API 키 준비 대기 상태로 되돌리지 않는다.
