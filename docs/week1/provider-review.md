# 검색 제공자 검토와 잠정 결정

확인일: 2026-09-21

## 결론

신규 프로젝트의 Google Custom Search JSON API 채택은 중단한다. Google은 신규 고객에게 이 API를 제공하지 않으며 기존 고객도 2027-01-01까지 대체 서비스로 전환해야 한다. 전 웹 검색 요구에는 Google이 별도 문의 경로를 안내하지만, 즉시 개발 가능한 공개 계약은 아니다.

Serper를 2주차 실제 연동의 잠정 후보로 둔다. 다만 Serper는 Google과 제휴하거나 승인받은 서비스가 아니며 공개 웹 데이터를 수집해 제공하는 B2B 서비스다. 계정 생성, API 키 보관 방식, 비용 승인, 검색어 처리 정책을 확인하기 전에는 실제 호출하지 않는다.

## 채택 조건

Serper는 다음 조건을 모두 충족할 때만 실제 Provider로 활성화한다.

1. 사용자가 계정 생성과 무료 크레딧 사용을 승인한다.
2. API 키는 백엔드 환경 변수로만 주입하고 프론트 코드와 로그에 남기지 않는다.
3. 최초 시험은 애슐리 퀸즈와 클로드 두 검색어, 검색어별 1회로 제한한다.
4. 애플리케이션의 자동 재시도는 비활성화한 채 응답 필드와 오류를 먼저 기록한다.
5. 무료 크레딧을 초과하거나 결제 수단 등록이 필요한 시점에 즉시 중단한다.
6. 제목·URL·snippet은 출처와 함께 표시하고 원문의 소유권을 오인시키지 않는다.

## 확인한 공식 자료

- Serper 이용약관: https://serper.dev/terms
- Serper 개인정보 처리방침: https://serper.dev/privacy

Serper 문서는 검색어 자체의 보관 기간을 명확히 설명하지 않는다. 따라서 개인 메모, 비공개 파일 내용, 개인정보가 포함된 검색어는 보내지 않는다. 이 항목은 실제 연동 전 추가 확인이 필요하다.
