# 1주차 완료 기록

기준일: 2026-09-21

## 범위

1주차는 실제 검색 연동 완료가 아니라 검색 경로와 정책을 정하고, 합성 데이터로 화면 골격과 서버 상태 확인 경로를 검증하는 단계다. 외부 검색 계정, 결제, API 키가 준비되지 않은 상태에서 실제 검색 성공을 주장하지 않는다.

## 산출물

- `requirements.md`: 필수·선택·제외·미확정 범위와 화면 상태
- `provider-review.md`: Google Custom Search JSON API와 Serper 비교 및 잠정 결정
- `policy-and-cost.md`: 외부 전송 정보, 저장 원칙, 비용 중단 조건
- `keyword-trial.md`: 애슐리 퀸즈·클로드 시험 계획과 미검증 사유
- `screen-sketch.md`: 제공된 화면 참고 이미지와 1주차 화면 상태
- `erd-draft.md`: 최소 데이터 모델 초안
- `environment.md`: 로컬 도구 버전과 보완 항목
- `fixture-inventory.md`: 합성 fixture 목록
- `validation.md`: 빌드·테스트·브라우저 검증 결과

## 구현 결과

- React Router와 TanStack Query Provider 유지
- 공통 사이드바·상단 바·검색·보관함·통계·상세 경로 구성
- `PageHeader`, `LoadingState`, `EmptyState`, `ErrorState` 공통 컴포넌트 추가
- 공식 후보와 사용자 글 후보 합성 카드 2건 및 상세 이동 추가
- 긴 한글 제목 줄바꿈과 모바일 레이아웃 처리
- Spring Boot Maven 프로젝트와 `GET /api/health` 추가
- 상태 확인 컨트롤러 단위 테스트 추가

## 완료 판정

| 기준 | 상태 | 근거 |
| --- | --- | --- |
| 제목·URL 확보 경로 결정 | 조건부 완료 | Serper를 잠정 후보로 정했으며 계정·비용 승인 전 실제 호출은 보류 |
| 실제 검증 또는 미검증 이유 | 완료 | API 키와 승인된 계정이 없어 provider 호출 미수행으로 기록 |
| 본문이 없는 경우의 정책 | 완료 | 제목·URL·snippet만 표시하고 본문 기반 분석을 금지 |
| 공식 여부 불명확 처리 | 완료 | 공식 확정이 아닌 `공식 후보`로 표시하고 도메인·운영 주체 확인 전 확정하지 않음 |
| 무료 범위와 과금 중단 조건 | 완료 | 무료 크레딧 내 수동 시험만 허용하고 유료 전환은 별도 승인 필요 |
| 화면 골격과 합성 카드 | 완료 | 검색·상세·보관함·통계 경로 및 합성 카드 구현 |
| 백엔드 상태 API와 테스트 | 완료 | `/api/health`와 단위 테스트 구현 |

실제 검색 완료 게이트는 통과하지 않았다. 다음 단계에서 승인된 Serper 계정과 API 키가 준비되면 두 키워드로 소량 스모크 테스트를 수행해야 한다.
