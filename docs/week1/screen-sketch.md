1주차는 최종 화면 전체를 구현하지 않고 공통 레이아웃, 검색 카드, 상세 자리, 빈 상태만 만든다. AI 피드, 실제 통계, 읽기 상태, 메모는 해당 주차 전까지 자리 표시와 설명만 유지한다.

## 경로

| 경로 | 1주차 내용 | 이후 연결 |
| --- | --- | --- |
| `/search` | 검색 입력, 합성 결과 2건, 실제 검색 아님 표시 | 3~4주차 Provider와 작업 상태 |
| `/documents/:documentId` | 합성 자료 상세와 목록 복귀 | 5~7주차 원문·보관·메모 |
| `/library` | 빈 상태 | 8주차 보관 자료 목록 |
| `/stats` | 빈 상태 | 8주차 집계와 차트 |
| 그 외 | 찾을 수 없음 상태 | 필요 경로 추가 시 갱신 |

## 공통 상태

- 검색 전: 입력 안내와 합성 결과 설명
- 처리 중: `LoadingState`에서 메시지 표시
- 성공 0건: `EmptyState`에서 조건 변경 안내
- 실패: `ErrorState`에서 부모가 전달한 재시도 동작 표시
- 기존 데이터 갱신 실패: 이후 주차에서 기존 결과를 유지하고 배너만 표시

## 반응형 규칙

- 데스크톱은 232px 사이드바와 본문으로 나눈다.
- 760px 이하에서는 사이드바를 상단 메뉴로 바꾼다.
- 검색 입력과 버튼을 세로로 배치한다.
- 긴 제목은 `overflow-wrap: anywhere`로 카드 밖에 넘치지 않게 한다.
