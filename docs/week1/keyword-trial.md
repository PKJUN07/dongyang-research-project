# 두 키워드 시험 기록

확인일: 2026-09-21

## 시험 상태

Serper 계정과 승인된 API 키가 없고 1주차 외부 호출 예산을 0건으로 정했으므로 실제 Provider 호출은 수행하지 않았다. 이 기록은 실제 검색 성공 보고가 아니라 다음 수동 스모크 테스트의 입력, 기대 필드, 판정 기준을 고정한다.

| 검색어 | 목적 | 기대 후보 | 확인 필드 | 현재 상태 |
| --- | --- | --- | --- | --- |
| 애슐리 퀸즈 | 매장·메뉴·가격처럼 시점과 지점에 따라 달라지는 정보를 공식 안내와 사용자 경험으로 분리 | 공식 브랜드·매장 안내, 뉴스, 후기 | title, link, snippet, position, 날짜 단서 | 실제 Provider 미검증 |
| 클로드 | 제품 공식 발표·업데이트와 사용자 활용 글을 버전·작성 시점별로 분리 | Anthropic 뉴스룸·도움말, 기술 기사, 사용 후기 | title, link, snippet, position, 날짜 단서 | 실제 Provider 미검증 |

## 합성 시험 결과

| 시나리오 | 입력 | 기대 결과 | 확인 결과 |
| --- | --- | --- | --- |
| 정상 | `success.json` | 공식 후보와 사용자 글 후보 2건, 제목·URL·snippet·순위 존재 | fixture 구조 준비 |
| 0건 | `empty.json` | 성공 상태와 빈 결과 배열을 오류와 구분 | fixture 구조 준비 |
| Provider 실패 | `error.json` | 안전한 오류 코드와 재시도 가능 여부 표시 | fixture 구조 준비 |

## 실제 스모크 절차

1. 사용자가 Serper 계정과 무료 크레딧 사용을 승인한다.
2. API 키를 백엔드 환경 변수로만 설정한다.
3. 각 검색어를 `gl=kr`, `hl=ko`, 결과 10건 이하로 한 번 호출한다.
4. 응답 시간, HTTP 상태, 결과 수, 누락 필드, 크레딧 차감을 기록한다.
5. 공식 후보·사용자 글 후보·기타 후보를 검색 순위와 별개로 분류한다.
6. 공개 HTML에 본문과 발행일이 있는지 소수 페이지만 확인하고 차단 시 중단한다.

## 통과 조건

- 두 검색어에서 제목과 URL을 안정적으로 얻는다.
- 공식 안내와 사용자 글 후보가 함께 나타난다.
- 필드 누락이 있어도 카드 렌더링이 실패하지 않는다.
- 비용 차감이 예상 범위와 일치한다.
- 본문 미확보 결과도 제목·링크·검색 요약으로 표시할 수 있다.
