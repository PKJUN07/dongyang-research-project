# 1주차 요구사항

## 제품 한 문장

관심 키워드로 찾은 웹 정보를 공식 정보와 사용자 경험으로 구분하고, 근거가 연결된 요약과 읽기 기록을 로컬에 보관하는 개인용 웹앱을 만든다.

## 필수 범위

- 검색 결과의 제목·URL·검색 요약 확보
- 공식·사용자·기타 출처 구분과 분류 근거 표시
- 접근이 허용된 공개 본문만 추출
- URL과 문서 내용의 중복 정리
- 결과 목록·필터·상세 화면
- 보관·읽음·즐겨찾기·메모
- 선택 주제의 기본 통계
- 로컬 Ollama 분석과 원문 근거 연결
- 검색·추출·분석 실패와 재시작 복구
- 검색 전, 처리 중, 성공 0건, 실패 상태의 구분

## 선택 범위

- 네이버 검색 Provider
- 임베딩 기반 추천
- 주간 브리핑
- 고급 편집기
- 복잡한 기간별 시각화

필수 기능이 완료되기 전에는 선택 범위를 시작하지 않는다.

## 제외 범위

- 다중 사용자 계정과 권한 관리
- 클라우드 운영과 외부 공개 배포
- 전체 웹 자체 색인
- Google 검색 결과 화면의 무단 자동 수집
- 로그인·유료벽·접근 제한 우회
- 외부 유료 AI 모델 자동 전환

## 미확정 사항

- Serper 계정 생성과 조직의 비용 승인
- 검색 결과 저장·재표시·AI 입력의 최종 법률 검토
- 공개 페이지 본문 자동 추출 허용 범위
- Ollama 모델과 설치 용량
- 실제 사용자 DB 위치와 백업 정책

## 1주차 화면 수용 기준

- 메뉴로 검색·주제 분석·읽기 보관함 화면을 이동할 수 있다.
- 합성 카드에서 자료 상세 경로로 이동할 수 있다.
- 페이지를 새로고침해도 현재 경로가 유지된다.
- 긴 한글 제목이 카드 너비를 넘지 않는다.
- 760px 이하에서 메뉴와 검색 폼이 사용할 수 있는 형태로 재배치된다.
- 모든 합성 자료에 실제 검색 결과가 아니라는 표시가 있다.
- 로딩·빈 결과·오류 컴포넌트는 API를 직접 호출하지 않는다.
