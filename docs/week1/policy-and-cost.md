# 정책과 비용 기록

확인일: 2026-09-21

## 외부로 보내는 정보

검색 Provider에는 사용자가 입력한 검색어, 언어 `ko`, 지역 `kr`, 작은 결과 수만 보낸다. 로컬 메모, 비공개 파일, 저장된 원문, 사용자 식별 정보, Ollama 입력은 보내지 않는다.

## 저장 원칙

- 제목·원문 URL·검색 요약·검색 순위·검색 시각·Provider 이름을 구분해 저장한다.
- snippet은 원문 본문으로 표시하지 않는다.
- 공식 여부를 도메인 이름만으로 확정하지 않는다. 운영 주체와 페이지 성격을 확인하기 전에는 공식 후보로 표시한다.
- 본문을 확보하지 못하면 `본문 확인 불가` 또는 `검색 요약만 제공` 상태를 사용한다.
- 원문 접근 조건, robots.txt, 사이트 이용 조건을 확인하고 차단을 우회하지 않는다.
- 제목·URL·작성자·출처 표시는 AI 요약으로 덮어쓰지 않는다.

## 비용 통제

- 1주차 실제 Provider 호출 예산: 0건
- 승인 후 최초 스모크 예산: 검색어 2개 × 1회, 합계 2회
- 자동 재시도: 최초 스모크에서 0회
- 무료 크레딧 사용만 허용
- 결제 수단 등록, 유료 크레딧 구매, 무료 한도 초과는 사전 승인 전 금지
- 응답 오류가 과금되는지는 실제 계정 대시보드와 제공자 지원 문서에서 확인
- 크레딧 잔액이 10% 이하이거나 예상치 못한 차감이 발생하면 즉시 중단

## 중단 조건

- 약관 또는 대상 사이트 정책이 저장·재표시를 허용하는지 판단할 수 없음
- 검색어 보관·삭제 정책이 요구사항과 충돌
- API 키가 프론트 번들, 로그, 오류 응답에 노출
- 401 또는 403 응답
- 429 응답과 `Retry-After` 확인 전 반복 호출
- 결제 등록 또는 유료 전환 요구
- 원문 접근이 로그인, 유료벽, 자동화 차단을 요구

## 사용자 표시 규칙

실제 Provider가 연결되기 전에는 화면 전체를 `합성 데이터 모드`로 표시한다. 실제 검색이 시작된 뒤에도 결과 카드에는 Provider, 수집 시각, 출처 분류 근거, 본문 확보 상태를 표시한다.
