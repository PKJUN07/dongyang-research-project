## 실행과 현재 라우팅

현재 세션은 기존 Serper 키를 다시 입력받거나 추출하지 않기 위해 검색 API18088을 유지하고 개선된 AI API18095를 같은 preview DB에 연결했다. AI 보조 인스턴스는 search-recovery-enabled=false여서 원본 검색 작업을 중단 처리하지 않는다. 프론트5178은 RESEARCH_API_TARGET=18088, RESEARCH_AI_TARGET=18095를 사용한다. 새로운 단일 서버 설치에는 빌드된 최신 JAR가 모든 API를 제공하므로 두 포트를 반드시 쓸 필요는 없다.

다음 실행 시 작업 공간 tools/Start-ResearchBoard-AI.ps1은 Ollama와 AI API가 없을 때만 실행한다. 모델 다운로드나 OS 자동 시작 설정 변경은 하지 않는다. 웹을 별도 실행할 경우 환경변수는 Vite 시작 전에 설정한다.

```powershell
$env:RESEARCH_API_TARGET='http://127.0.0.1:18088'
$env:RESEARCH_AI_TARGET='http://127.0.0.1:18095'
npm run dev -- --host 127.0.0.1 --port 5178 --strictPort
```
